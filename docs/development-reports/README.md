# Development Reports

This directory contains repository-local end-of-day development reports.

Reports use the filename:

YYYY-MM-DD.md

Each report should record:

- repository and work date
- sealed phase at workday start
- current phase at workday end
- meaningful Git/PR activity
- implementation delta
- tests and quality gates
- CI state
- canonical anchors created that day
- unresolved issues
- next bounded work

Reports distinguish completed evidence from planned work.

Where practical, reports have a repository-local audit script under:

scripts/audit/
